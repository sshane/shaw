Shaw bundled samples: credits and sources
==========================================

Every recording in this folder is in the public domain under Creative Commons CC0 1.0
Universal (https://creativecommons.org/publicdomain/zero/1.0/). The Bass Guitar comes from
Karoryfer Growlybass (see the end of this file). Everything else comes from the Versilian
Community Sample Library (VCSL) by Versilian Studios LLC and its contributors.
No rights are reserved; attribution is not required but is given here with thanks.

  VCSL:              https://github.com/sgossner/VCSL
  Versilian Studios: https://versilian-studios.com/

The Pipe Organ and the Knight upright piano were sampled by Simon Dalzell of Ivy Audio
(organ: Winter 2015-16; upright: for the VSCO 2 Pro sample set).

Processing for Shaw: leading silence trimmed, tails trimmed with a short fade, one gain
per instrument (drums and percussion normalized per file), converted to 16-bit Apple
Lossless CAF at the original sample rate. The Kalimba notes were retuned by resampling
(by -36 to +36 cents) to equal temperament, because the source instrument uses its own
traditional tuning. Instrument files are named by the MIDI note of the recorded pitch.

Source paths are relative to the root of the VCSL repository (branch master).

Bass Guitar
===========

Source: Karoryfer Growlybass, a Squier Jazz Bass sample library (EADG tuning, roundwound strings,
recorded direct with both pickups) by Karoryfer Lecolds.

  Repository:        https://github.com/sfzinstruments/karoryfer.growlybass
  Commit used:       4f483268fc66b5a6d5781d421c0d11b8d08d3fc6 (branch master)
  Karoryfer Samples: https://www.karoryfer.com (shop: https://shop.karoryfer.com)
  License:           CC0 1.0 Universal (public domain dedication); the full LICENSE text is below.
  Readme statement:  "Royalty-free for all commercial and non-commercial use."
                     "Copyright 2014 Karoryfer Lecolds."

Shaw uses the sustained notes (no release samples, staccato notes, or pick scrapes), the "f" velocity
layer (the second loudest of four), and round robin 1. The library names its files one octave above
the sounding pitch, so e2_f_rr1.wav sounds E1 (MIDI 28).

Processing: leading silence trimmed with 2 ms of pre-roll and a 1 ms fade-in; every source is 6.0 s
long and still ringing at its end, so each file keeps the full 6 s with a fade over the last 10%;
one gain (+0.2 dB) for the whole instrument so the loudest file peaks at -1 dBFS; 16-bit with TPDF
dither; Apple Lossless in CAF; 44.1 kHz mono, as recorded. Shaw's file names give the sounding MIDI
note.
